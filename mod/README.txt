Statecraft (Diplomacy, Espionage, Faction Reworks) [Submod TR 3.51]
=======================================================================

Install
-------
1. Subscribe to Thrawn's Revenge (1125571106) and Statecraft.
2. Copy POWRPROF.dll from the Statecraft Workshop folder into ...\Star Wars Empire at War\corruption\
3. Steam launch options: STEAMMOD=3819016148 STEAMMOD=1125571106
4. Start Forces of Corruption and begin a new campaign.

Uninstall: unsubscribe, delete POWRPROF.dll (and POWRPROF.dll.old, if there) from corruption\, and clear the
launch options.

The first start after installing or updating takes a few seconds longer while the mod builds its files from
your Thrawn's Revenge install.

Steam never updates POWRPROF.dll in corruption\. When an update brings a new one, the game tells you once:
copy it again as in step 2.

POWRPROF.dll only writes to the mod's own folder, and its log is Logs\Statecraft_Engine.log (please include it
with bug reports). Third-party licences are in Licenses.txt. Source code:
https://github.com/Skorotoro/Statecraft-Mod-EaW-Thrawn-s-Revenge-Submod-
